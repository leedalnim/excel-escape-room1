# Episode 1. 비밀 — 웹 방탈출 게임

브라우저에서 바로 즐기는 텍스트 기반 방탈출 게임입니다.
별도 설치 없이 `index.html` 한 파일로 동작합니다.

## 플레이 방법

- **온라인**: GitHub Pages로 배포된 주소에 접속하면 바로 플레이할 수 있습니다.
- **로컬**: `index.html` 파일을 더블클릭해 브라우저에서 열면 됩니다.

## GitHub Pages 배포 방법

1. 이 저장소의 **Settings → Pages** 메뉴로 이동합니다.
2. **Source**를 `Deploy from a branch`로 선택합니다.
3. 배포할 브랜치(예: `main`)와 폴더(`/root`)를 지정한 뒤 저장합니다.
4. 잠시 후 `https://<사용자명>.github.io/excel-escape-room1/` 주소에서 게임이 열립니다.

## 특징

- 단일 HTML 파일 (외부 의존성: Google Fonts만 사용)
- 인벤토리, 장소 이동, 시트(단서) 열람, 저장/불러오기 지원
- 분위기 연출(빈티지 세리프 폰트, 그레인/비네팅 효과)
